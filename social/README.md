# Delta social

**Status: draft, being written.** Nothing on these pages is final yet.

The social parts of Delta: what lets players find each other and play
together across ports and networks.

| Part | What it covers |
| --- | --- |
| Friends | requests, the list, blocking |
| Presence | online, in a game, appearing offline |
| Invites and joins | inviting a friend, joining a friend's game |
| Parties | a group that moves between games together |
| Party chat | text between a party's members outside a game |
| Clans | groups with a name, tag, emblem and ranks |
| Platform icons | which platform a friend plays on |
| Voice | talking in a party and in a game |
| Chat bridge | chat between Delta and games without it |

Some of this is already in use and described elsewhere: clans and the
doorbell in [link.md](../link.md), chat, voice and party teams in
[peer.md](../peer.md). These pages will gather it in one place, for any
network. [comparison.md](comparison.md) will compare it with other
projects' social systems.
